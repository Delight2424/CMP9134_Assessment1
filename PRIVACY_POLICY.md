# Privacy Policy

## What Personal Data We Collect
The system collects usernames, timestamps of robot commands, and IP addresses. This data is recorded in the mission log (audit trail).

## Why We Collect This Data
The data is collected to ensure safety, accountability, and auditing of robot actions. It allows the system to track who issued each command.

## How We Protect This Data
Access to audit logs is restricted using Role-Based Access Control (RBAC). Only authorized roles such as "Auditor" can view sensitive logs. All user accounts are password protected.
